# cursor

An interactive cursor-tracking mascot web application built with React, Vite, TypeScript, and [`page-mascot`](https://github.com/nilbuild/page-mascot).

## Features
- **3D Cartoon Avatar**: Smooth custom mascot tracking the cursor across 8 directions + center.
- **Minimalist Aesthetic**: Pure black background (`#000000`) with centered focus on the avatar.
- **Interactive Reactions**: Natural animations and gaze tracking driven by cursor position.

## Tech Stack
- React 19
- TypeScript
- Vite
- page-mascot

## Getting Started

### Installation
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```
